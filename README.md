Coffee Haven

Coffee Haven is an interactive coffee shop web application built using HTML, CSS, and JavaScript. The project provides a multi-page interface where users can explore the menu, log in, add items to their cart, manage reviews, and book a table.
The application uses JavaScript to dynamically display menu items and manage user interactions. LocalStorage is used to maintain the cart, login state, and customer reviews even after the page is refreshed.

Technologies Used
HTML5, CSS3, JavaScript, and LocalStorage.

Features
The application includes a client-side login system, dashboard access control, dynamic menu rendering, shopping cart functionality, customer reviews, and table booking with form validation.
